Compose file

This is the file you download in the Quick Start. It is generated from the project's own deployment files, so it always matches the images it starts.

Download it: compose.yaml

How it differs from the repository's docker-compose.yaml​

The services, health checks, networks, volumes and security settings are identical. Only what a source checkout provides is replaced, so the file works on its own:

Repository fileThis fileWhy
build: sectionsRemovedYou pull published images instead of building them.
Image registry preflyt-localghcr.io/lyrisoftWhere the published images live.
PREFLYT_VERSION defaults to developmentRequiredYou must choose a release. There is no default to run by accident.
./deploy/... file mountsInline configsThe database setup script and the optional telemetry collector settings are embedded, so there are no extra files to download. This is why Compose 2.23.1 is needed.
NODE_ENV and COOKIE_SECURE fixed to production valuesPREFLYT_NODE_ENV and PREFLYT_COOKIE_SECURE, defaulting to productionLets the local trial run over http://localhost. Leave them unset on a real deployment.

  db_init:
    content: |
      #!/bin/sh
      set -eu
      : "$${DATABASE_APP_PASSWORD:?DATABASE_APP_PASSWORD is required}"
      psql -v ON_ERROR_STOP=1 --username "$$POSTGRES_USER" --dbname "$$POSTGRES_DB" \

      SELECT format('CREATE ROLE preflyt_app LOGIN NOSUPERUSER NOCREATEDB NOCREATEROLE NOINHERIT PASSWORD %L', :'app_password') \gexec
      GRANT CONNECT ON DATABASE preflyt TO preflyt_app;
      GRANT USAGE ON SCHEMA public TO preflyt_app;
      ALTER DEFAULT PRIVILEGES FOR ROLE preflyt_owner IN SCHEMA public
        GRANT SELECT, INSERT, UPDATE, DELETE ON TABLES TO preflyt_app;
      ALTER DEFAULT PRIVILEGES FOR ROLE preflyt_owner IN SCHEMA public
        GRANT USAGE, SELECT ON SEQUENCES TO preflyt_app;
