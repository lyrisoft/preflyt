# Same-run CI coverage — 2026-10-15

## Implementation

Development runs the API unit suite once, including workflow/source contracts, with V8 coverage enabled. The existing full policy browser command produces both its genuine JUnit report and LCOV during that execution. There is no separate coverage test job or duplicate browser run. API and policy jobs remain parallel; a one-day artifact transfers the API report with repository, PR head, workflow run/attempt and original SHA-256 context. Tests and coverage outputs are not cached.

The companion Action accepts fresh local reports and an optional same-run artifact, namespaces package paths, validates counters, and unions matching physical lines. It attaches optional `tests.coverage` without altering policy results or adding a threshold. Only the coverage boolean passes through its command credential filter; platform credentials remain excluded. Requested missing/stale/mismatched reports fail attachment. Artifact lookup is read-only and bounded to 120 seconds, followed by the pinned official GitHub artifact download action.

LCOV transport uses deterministic gzip/base64 with its decoded SHA-256. Intake caps compressed data at 256 KiB and decoded coverage at 2 MiB, rejects malformed encoding/UTF-8/digests and bounds decompression. Stored bytes are decoded original canonical LCOV. Artifact parsing and subsequent evidence validation use the same coverage limit; other reports keep their existing limit. Health accepts unsigned coverage only with the same server-verified exact GitHub execution receipt used by policy checks in default `github-native` mode. Explicit organization-key proof requirements and rejection of invalid supplied signatures remain enforced. Manual report upload alone cannot establish coverage.

## Scope and release boundary

Coverage describes configured source scope. API excludes generated Prisma code and type declarations; web retains its existing UI primitive, route, asset, generated-tree and test-helper exclusions. Explicit source includes retain untested modules. The percentage is not a whole-repository quality claim. Health looks up the exact displayed assessment commit, never copies PR coverage onto a different merge/squash SHA, and the current development PR intake does not submit evidence for later push SHAs. Main regression is unchanged.
