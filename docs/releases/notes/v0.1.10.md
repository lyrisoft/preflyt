Review security findings in one place, connect your coding agent to investigate them, and see clearer explanations of the affected code.

## What's new

- **AI security reviews:** run an optional source-code security review using your configured AI model. Each review uses the selected commit, with configurable token and request limits. Findings include the model's reasoning and suggested remediation; they remain advisory.
- **Coding-agent connections:** connect a coding agent from Integrations using the Model Context Protocol (MCP). Connections are personal and limited to repositories you approve. Open a finding to prepare an investigation task and attach external review evidence. An optional local companion supports local investigation workflows.
- **Model usage:** see recorded input tokens, output tokens and requests for each configured model. Missing usage stays unknown; these figures are not a provider billing statement.

## Improvements and fixes

- **Consistent security findings:** source AI findings appear alongside scanner findings in repository reports. Security totals, severity charts and paginated results use the same findings, reducing confusing differences between cards and lists.
- **Faster findings lists:** saved summaries and background indexing reduce repeated work when opening large report collections.
- **Clearer finding details:** review affected code, reasoning, suggested fixes and the saved assessment together. External agent evidence does not change scan outcomes or authorize merges.
- **Longer review skills:** upload Markdown files up to 128 KiB, with descriptions up to 2,000 characters and instructions up to 24,000 characters. Validation identifies the failing field and submitted length instead of showing a generic error.
- **Simpler workspace controls:** the organization header is a plain label for the supported single-organization setup. Report a bug or suggest an improvement from the account menu; Preflyt opens a prefilled GitHub issue for you to review before submitting it publicly.

## Upgrade notes

- **Database migrations are required.** This release adds storage for security reviews, model usage, agent connections and the findings index. Back up your database and encryption keys, pull the matching images, run the migration service, and restart the application and worker using the [Compose upgrade guide](https://docs.preflytlabs.com/self-hosting/upgrades-and-backups).
- Review the updated Compose configuration when upgrading: the scanner and background worker are needed for their respective review and indexing jobs. Replacing only the web image does not upgrade those services.
- AI security reviews require an approved model and source-sharing configuration. Review per-scan limits before starting one; model requests can incur provider charges.
- For a deployment behind a reverse proxy, verify the public API address used by coding-agent connections. The default is `WEB_ORIGIN` followed by `/api`; set `PREFLYT_PUBLIC_API_URL` when the external API address differs.
- Image downgrades do not undo database migrations. Keep a verified backup for recovery.
