# Support

Use the [documentation](https://docs.preflytlabs.com/) for installation and operation. Include the exact Preflyt version/image digest, architecture, deployment method and relevant Action version when seeking help.

For non-sensitive defects, use the [bug template](https://github.com/lyrisoft/preflyt/issues/new?template=bug_report.yml); for proposals use the feature-request template. Repository access is still restricted while Community launch preparation is in progress. You can contact **support@lyrisoft.tech** if the issue tracker is unavailable. Do not post populated environment files, keys, tokens, backups, private source or customer evidence.

Community help is best effort, with no guaranteed response time or SLA. Check existing reports and provide a small sanitized reproduction. Do not rerun expensive builds repeatedly without first collecting the underlying error and affected versions.

For vulnerabilities use [SECURITY.md](SECURITY.md), and for conduct concerns use [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Both have private reporting instructions.

Managed Cloud is planned, not an available service promised here. Commercial support, onboarding or service commitments require a separate agreement with Lyrisoft. Community Edition remains self-hosted with no artificial repository-count limit; operators supply infrastructure, GitHub configuration and any optional AI credentials.
