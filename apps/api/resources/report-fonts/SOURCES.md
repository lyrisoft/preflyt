# PDF report assets

Noto Sans Regular and Bold are unmodified fonts from the official [Noto fonts project](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans). Their SIL Open Font License is retained in `LICENSE`. They are bundled so PDF generation never fetches remote fonts.

The adjacent `preflyt-logo-color.png` is an unchanged copy of the application's supplied brand asset at `apps/web/public/images/brand/logo-color.png`. Keep it aligned with that asset when branding changes. The PDF places it on a dark header to preserve the original white wordmark.
